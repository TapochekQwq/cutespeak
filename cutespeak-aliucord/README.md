# CuteSpeak для Aliucord — «милый режим» на телефоне

Порт плагина CuteSpeak v2 (Vencord) под **Aliucord** (Android). Превращает твои исходящие сообщения в «милые» по-русски:
заикания, растягивания, г→к, каомодзи, *действия*, 8 стилей. База слов, каомодзи, действий и склонений та же, что в версии для Vencord:
движок портирован на Kotlin, данные сгенерированы из тех же исходников.

## Как собрать и поставить
1. Нужны JDK 21 и интернет (Gradle скачает Aliucord и Android-зависимости).
2. В корне репозитория: `./gradlew CuteSpeak:make` (Windows: `gradlew.bat CuteSpeak:make`).
3. Готовый файл — `plugins/CuteSpeak/build/outputs/CuteSpeak.zip`.
4. Положи его на телефон в `Aliucord/plugins/` (во внутренней памяти) и перезапусти Aliucord. Включи плагин в *Настройки → Плагины*.

Без компьютера: залей папку в свой GitHub-репозиторий — workflow `.github/workflows/build.yml` соберёт плагин сам, готовый zip будет в артефактах сборки.

Перед публикацией поменяй в `plugins/build.gradle.kts` автора и ссылку на репозиторий. При каждом обновлении увеличивай `version` в `plugins/CuteSpeak/build.gradle.kts`.

## Как пользоваться на телефоне
- **Сердечко в поле ввода:** тап — включить/выключить режим *для этого чата*; долгий тап — быстрая панель (режим и стиль чата, сила, главные эффекты).
- **Долгое нажатие на своё сообщение → CuteSpeak:** «Переколдовать (новый вариант)», «Вернуть оригинал» или «Сделать милым». Откат работает, пока Discord не перезапущен.
- **Настройки плагина** (значок шестерёнки у плагина): сверху **«Примерка»** (напиши фразу — получишь 5 вариантов, тап копирует), ниже все эффекты, ползунки, свои слова, защита слов, лимит 2000/4000.
- **Команды:** `/cute текст [стиль]` — отправить один раз; `/cutepreview текст [стиль]` — 5 вариантов только тебе; `/cutemode [состояние] [стиль]` — режим и стиль в этом чате.
- **Префикс `//`** в начале сообщения — отправить как есть.

## Что отличается от версии для Vencord
Нет правого клика и контекстных меню каналов — вместо них долгий тап и быстрая панель. Настройки режима на отдельный чат
делаются сердечком, а не меню канала. Всё остальное (стили, словарь, склонения, смайлики, защита серьёзных тем, время суток, сезонные эмодзи) — то же.

## Структура
- `plugins/CuteSpeak/src/main/kotlin/com/cutespeak/engine/` — движок (чистый Kotlin, без Android) и данные (`data/` — автогенерация).
- `plugins/CuteSpeak/src/main/kotlin/com/cutespeak/` — Android-часть: `CuteSpeak.kt` (хуки, кнопка, меню сообщений, команды), `CuteSettingsPage.kt`, `QuickSheet.kt`, `Ui.kt`, `Prefs.kt`, `CuteCore.kt`.
- `tools/engine-test/CuteTest.kt` — тесты движка на обычной JVM (склонения, защита кода/ссылок/упоминаний, разметка, длина, серьёзные темы, фаззинг):
  ```
  kotlinc plugins/CuteSpeak/src/main/kotlin/com/cutespeak/engine/*.kt plugins/CuteSpeak/src/main/kotlin/com/cutespeak/engine/data/*.kt tools/engine-test/CuteTest.kt -include-runtime -d test.jar
  java -jar test.jar
  ```
